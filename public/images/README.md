Put project images here, one folder per project slug, e.g. `images/retail-starter-kit/hero.jpg`.

Export JPG or WebP at about 2400 px on the long side for full-width images and 1600 px for the rest, under ~500 KB each.
Then set `src` in the project file, e.g. `src: 'images/retail-starter-kit/hero.jpg'`, and write a short `alt` text.
